ensave プライバシーポリシー

制定日：2026年9月19日
最終更新日：{{PUBLISH_DATE}}

ensave運営者（以下「運営者」）は、モバイルアプリ「ensave（エンセーブ）」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 適用範囲

本ポリシーは、iOS 版の本アプリと、本アプリに関するお問い合わせにおける利用者の情報の取り扱いに適用されます。本アプリから開く外部のサービス（LINE など）での情報の取り扱いには、それぞれのサービスのプライバシーポリシーが適用されます。

2. 取得する情報

本アプリは、次の情報を取得します。

(1) 利用者が本アプリに入力する情報

  • 支出の記録（金額、日付、カテゴリ、支払い方法、内容、メモ）
  • 予算、カテゴリ、支払い方法の設定
  • 表示名（任意。共有機能で相手に表示されます）

(2) アカウントに関する情報

  • 本アプリの利用を始めたときに発行される利用者 ID。本アプリは、利用者が「ensaveをはじめる」を選んだときにだけ、この ID を発行します。氏名やメールアドレスを登録しなくても利用できます。
  • アカウント連携（任意）を行った場合は、連携方法に応じた次の情報：
    • メールアドレスで連携した場合：メールアドレス
    • Google で連携した場合：Google から認証のために提供されるアカウント識別情報、メールアドレス等
    • Apple で連携した場合：Apple から認証のために提供されるアカウント識別情報、メールアドレス（「メールを非公開」を選んだ場合は、Apple が発行する中継用のメールアドレス）等

(3) 共有機能に関する情報

共有機能を使った場合、ペアを組んだ2人の利用者 ID と表示名、共有の支出を登録した人の利用者 ID、招待コードとその有効期限を取得します。

(4) 自動的に取得する情報

  • 利用状況に関する情報（第6条）
  • クラッシュやエラーに関する情報（第7条）

3. 利用目的

取得した情報は、次の目的に限って利用します。

  1. 支出や予算の記録、残高の計算、カレンダーの表示、2人での共有など、本アプリの機能を提供するため
  2. アカウント連携を行った場合に、機種変更や再インストールのあともデータを使えるようにするため
  3. 本アプリの利用状況を分析し、サービスを改善するため
  4. 不具合を検知・調査し、品質を改善するため
  5. お問い合わせに対応するため

運営者は、取得した情報を広告の配信や、広告のための利用者の追跡には利用しません。

4. 共有機能に関する情報

  1. 本アプリでは、招待コードを使って2人で「共有」の家計簿を使えます。「共有」として記録した支出・予算・カテゴリ・支払い方法は、現在ペアを組んでいる2人だけが閲覧・編集・削除できます。
  2. 「自分」として記録した情報は、ペアの相手を含め、他の利用者には表示されません。
  3. 共有の支出には、どちらが登録したかが記録され、相手にも表示されます。
  4. 招待コードは発行から7日で無効になり、一度使うと削除されます。期限が切れた招待コードは、発行した利用者が本アプリを起動したときや、招待コードを発行し直したときに削除します。そのため、発行した利用者が期限切れのあとに本アプリを使わない場合、期限切れの招待コードの情報（有効期限、発行者の利用者 ID など）が残ることがあります。期限切れの招待コードは参加に使えず、発行者以外は内容を読み取れません。
  5. 「LINEで招待する」を選ぶと、招待コードを含むメッセージを LINE アプリに渡します。本アプリが LINE に渡すのは、このメッセージだけです。

5. Firebase Authentication

本アプリは、利用者 ID の発行とアカウント連携のために、Google LLC が提供する Firebase Authentication を使います。アカウント連携を行った場合、第2条(2)の情報は Firebase Authentication に保存されます。家計のデータは、同じく Google LLC が提供する Cloud Firestore に保存されます。

6. Google Analytics for Firebase

  1. 本アプリは、利用状況を分析してサービスを改善するために、Google LLC が提供する Google Analytics for Firebase を使います。
  2. 本アプリが送る情報は、初回の案内やガイドの進み具合、予算を初めて設定したこと、支出を登録したこと（「自分」か「共有」かの区別を含む）といった操作の情報です。支出の金額・内容・メモ、カテゴリ名、支払い方法名、表示名、メールアドレス、利用者 ID、招待コードは送りません。
  3. このほか、Google Analytics for Firebase の仕組みにより、端末・OS・アプリのバージョン、利用環境に関する情報、おおよその地域、アプリのインストール単位の識別情報などが自動的に取得される場合があります。
  4. 本アプリでは広告 ID（IDFA）を利用せず、Google Analytics の広告パーソナライズおよび Google Signals を無効にしています。
  5. 送られた情報は、Google Analytics のデータ保持の設定（2か月）に従って保持されます。アカウントを削除すると端末上の分析用データと識別情報はリセットされますが、すでに送られた情報は、この保持設定に従って扱われます。

7. Firebase Crashlytics

  1. 本アプリは、不具合の検知と品質改善のために、Google LLC が提供する Firebase Crashlytics を使います。
  2. アプリがクラッシュした場合やエラーが起きた場合に、エラーの内容と発生箇所、端末の種類、OS やアプリのバージョンなどが送られます。本アプリは、利用者 ID や家計のデータを Crashlytics に意図して付け加えることはしません。ただし、エラーの内容に、データの保存場所を示す文字列（利用者 ID を含むことがあります）が含まれる場合があります。
  3. 送られた情報は、Firebase Crashlytics の保持期間に従って保持されます。

8. 外部サービス

本アプリは、本アプリの提供に必要な範囲で次の外部サービスを利用し、情報を送信し、または取り扱わせることがあります。各サービスでの情報の取り扱いは、それぞれのプライバシーポリシーをご確認ください。

  • Firebase（Authentication、Cloud Firestore、Google Analytics for Firebase、Crashlytics）：Google LLC
    • Google プライバシーポリシー：https://policies.google.com/privacy
    • Firebase のプライバシーとセキュリティ：https://firebase.google.com/support/privacy
  • Sign in with Apple：Apple Inc.（Apple で連携した場合）
  • Google ログイン：Google LLC（Google で連携した場合）
  • LINE：LY株式会社（「LINEで招待する」を選んだ場合）

本アプリは、カメラ、写真、位置情報、連絡先へのアクセスや、トラッキングの許可を求めません。

9. データの保存期間

  1. 本アプリに記録した情報は、利用者が削除するか、アカウントを削除するまで保存します。
  2. 支出を削除すると、Cloud Firestore 上の当該記録を削除します。
  3. 期限切れの招待コードの情報は、第4条第4項のとおり、残ることがあります。
  4. 利用状況に関する情報とクラッシュ・エラーに関する情報は、第6条・第7条のとおり、各サービスの保持設定に従います。

10. ペア解除時のデータ

ペアを解除すると、次の情報を削除します。

  • ペアの2人が「共有」として記録した支出（相手が登録したものを含む）
  • 共有の予算、カテゴリ、支払い方法
  • ペアの情報と、そのペアの招待コード

それぞれが「自分」として記録した情報は削除しません。解除した共有の情報は、本アプリ上で復元できません。

11. アカウント削除

  1. 本アプリの「設定 → データとアカウント → アカウント連携・アカウント削除 → アカウントを削除する」（バージョン 1.1.0 以降。1.1.0 より前のバージョンでは「設定 → アカウント連携 → アカウントを削除する」）から、アカウントを削除できます。
  2. アカウントを削除すると、次の情報を削除します。
    • 「自分」として記録した支出、予算、カテゴリ、支払い方法
    • 表示名などのアカウントの情報
    • 発行した招待コード
    • Firebase Authentication のアカウント（連携したメールアドレスなどの情報を含む）
    • ペアを組んでいた場合は、第10条の共有の情報（相手が登録した共有の支出を含む）
  3. ペアの相手が「自分」として記録した情報は削除しません。
  4. Apple で連携していた場合は、Apple が発行した認証情報を無効にします。Google で連携していた場合は、本アプリと Google アカウントの連携を解除します。Apple ID や Google アカウント自体は削除しません。
  5. 端末に保存されている本アプリのデータの一時保存（キャッシュ）と、分析用のデータをリセットします。
  6. 削除したアカウントとデータは、本アプリ上で復元できません。
  7. 本アプリが削除のあとに自動で新しいアカウントを作ることはありません。再び使う場合は、「ensaveをはじめる」を選ぶと、新しいアカウントで始まります。
  8. 利用状況に関する情報とクラッシュ・エラーに関する情報のうち、すでに送られたものは、第6条・第7条の保持設定に従います。

削除の手順と注意点は、アカウントの削除についてをご覧ください。

12. 安全管理

運営者は、情報への不正なアクセスなどを防ぐため、アクセス制御の設定を行います。本アプリでは、アクセス制御により、他の利用者からは、本人の情報には本人だけが、共有の情報には現在ペアを組んでいる2人だけがアクセスできるように設定しています。

13. 第三者提供

運営者は、法令に基づく場合または利用者の同意がある場合を除き、利用者の情報を第三者へ販売・提供しません。利用者が共有機能を使った場合、第4条のとおり、共有の情報はペアの相手に表示されます。

なお、本アプリの提供に必要な範囲で、第8条に記載する外部サービスを利用し、情報を送信し、または取り扱わせることがあります。

14. 未成年者について

未成年の方が本アプリを利用する場合は、必要に応じて保護者その他の法定代理人の同意を得たうえで利用してください。

15. プライバシーポリシーの変更

運営者は、法令の変更、本アプリの機能変更その他必要に応じて、本ポリシーを変更することがあります。変更した場合は、本ページに変更後の内容および最終更新日を掲載します。利用者への影響が大きい変更については、必要に応じて本アプリ内その他適切な方法でお知らせします。
