ensave 利用規約

制定日：2026年9月19日
最終更新日：{{PUBLISH_DATE}}

この利用規約（以下「本規約」）は、ensave運営者（以下「運営者」）が提供するモバイルアプリ「ensave（エンセーブ）」（以下「本アプリ」）の利用条件を定めるものです。利用者は、本規約に同意したうえで本アプリを利用するものとします。

第1条（サービス概要）

  1. 本アプリは、支出・予算などを記録する家計簿アプリです。1人で使うことも、招待コードを使って2人で「共有」の家計簿を使うこともできます。
  2. 本アプリは、現時点では無料で利用できます。将来、有料の機能を提供する場合は、その利用を始める前に、料金その他の条件を明示します。
  3. 本アプリの利用に必要な通信料などは、利用者の負担とします。

第2条（利用条件）

  1. 利用者は、本規約とプライバシーポリシーに同意したうえで、本アプリを利用するものとします。
  2. 未成年の方が本アプリを利用する場合は、必要に応じて保護者その他の法定代理人の同意を得たうえで利用してください。
  3. 本アプリは、「ensaveをはじめる」を選んだときに発行されるアカウントで利用します。アカウント連携（メールアドレス・Google・Apple）は任意です。
  4. アカウント連携をしていない場合、機種変更などで別の端末に移ったときに、データを引き継げないことがあります。

第3条（禁止事項）

利用者は、本アプリの利用にあたり、次の行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. 他人の情報を無断で登録・利用する行為、他人になりすます行為
  3. 他の利用者の情報に不正にアクセスし、または取得しようとする行為
  4. 本アプリやサーバーに過度な負荷をかける行為、動作を妨げる行為
  5. 本アプリを改変・解析（リバースエンジニアリングを含む）し、または不正な方法で利用する行為（法令で認められる場合を除きます）
  6. 招待コードを不正に取得し、または利用する行為
  7. 共有機能を使って、相手に不快感や不利益を与える内容を登録する行為
  8. その他、運営者が不適切と合理的に判断する行為

第4条（利用者の責任）

  1. 利用者は、自分の端末と、アカウント連携に使うメールアドレス・Google アカウント・Apple ID などを、自らの責任で管理するものとします。
  2. 利用者が自分の端末やアカウントの管理を怠ったことにより生じた結果については、運営者に故意または重大な過失がある場合を除き、利用者が責任を負うものとします。

第5条（入力内容の責任）

  1. 利用者が本アプリに入力した支出・予算・表示名などの内容は、利用者が責任を負うものとします。
  2. 本アプリの残高や集計の表示は、利用者が入力した内容をもとに計算したものです。実際の口座残高や支払い状況と一致することを保証するものではありません。
  3. 本アプリは、金融・税務・会計などに関する助言を提供するものではありません。

第6条（ペア共有の扱い）

  1. 共有機能は、招待コードを使って、2人の利用者の間でだけ利用できます。
  2. 「共有」として記録した支出・予算・カテゴリ・支払い方法は、ペアを組んでいる2人のどちらも閲覧・編集・削除できます。共有の支出には、どちらが登録したかが記録され、相手にも表示されます。
  3. 「自分」として記録した情報は、ペアの相手には表示されません。
  4. 招待コードは発行から7日で無効になり、一度使うと削除されます。利用者は、招待コードを共有したい相手以外に知らせないでください。
  5. どちらかがペアを解除した場合、または、ペアを組んでいるどちらかがアカウントを削除した場合は、2人分の共有の情報（相手が登録した共有の支出を含みます）が削除されます。削除された共有の情報は、本アプリ上で復元できません。
  6. 共有の情報の編集・削除・ペア解除をめぐって利用者間で生じたトラブルは、利用者同士で解決するものとします。ただし、運営者の故意または重大な過失による場合を除きます。

第7条（アカウントの削除）

利用者は、本アプリの「設定 → データとアカウント → アカウント連携・アカウント削除 → アカウントを削除する」（バージョン 1.1.0 以降。1.1.0 より前のバージョンでは「設定 → アカウント連携 → アカウントを削除する」）から、いつでもアカウントを削除できます。削除される情報と注意点は、アカウントの削除についてとプライバシーポリシーに記載します。

第8条（サービスの変更・停止・終了）

  1. 運営者は、必要に応じて、本アプリの内容を変更し、または提供を一時的に停止することがあります。
  2. 運営者は、本アプリの提供を終了する場合、原則として終了日の30日前までに、本アプリ内または公開ページでお知らせします。ただし、緊急その他やむを得ない事情がある場合は、この限りではありません。
  3. 本アプリの提供を終了する場合の、保存されている情報の取り扱いと削除の時期は、終了のお知らせの際にご案内します。

第9条（免責）

  1. 運営者は、本アプリに不具合がないこと、特定の目的に適合すること、常に利用できることを保証するものではありません。
  2. 通信環境や端末、外部サービス（Firebase、Apple、Google、LINE など）の障害や仕様変更などにより、本アプリが利用できない場合や、データが正しく保存・表示されない場合があります。
  3. 運営者は、本アプリの利用に関して利用者に生じた損害について、運営者の故意または重大な過失による場合を除き、責任を負いません。ただし、消費者契約法その他の法令により、この免責が認められない場合は、この限りではありません。
